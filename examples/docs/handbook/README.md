# Team handbook

This handbook describes how the example web application is built, deployed and operated.

## Where to start

- [[deploy]] explains how a release reaches production.
- [Backups](ops/backups.md) covers what is backed up and how to restore it.
- Daily numbers come from the report query in `sql/reports/daily.sql`.

## Conventions

Every document has one owner. When a procedure changes, update the document in the same pull request
as the code, and move the old version to `archive/` instead of deleting it.
